{% seo %} {% comment %} This layout deliberately overrides the one shipped with jekyll-theme-cayman. The theme's head emits two requests to Google on every page load: Both hand the visitor's IP address and user agent to a third party before the visitor has done anything, which is the fact pattern in LG Muenchen I, 3 O 17493/20 (Google Fonts), and it is the one thing our privacy policy would otherwise have to disclose about a site that collects nothing else. Removing them costs no appearance. The preload has no consumer: there is no matching rel=stylesheet and no onload swap, so the stylesheet is fetched and never applied. The theme's own stack already resolves to "Open Sans", "Helvetica Neue", Helvetica, Arial, sans-serif, so a visitor with Open Sans installed still gets it locally and everyone else sees the same fallback they saw before. Verified against the built site on 2026-08-11 before this file was written. The theme's _includes/head-custom.html is also not included here. It carries a Google Analytics block driven by site.google_analytics, which would inject a tracker with no consent gate the moment that key appeared in _config.yml. Analytics on Onchain Bridges properties runs behind the consent gate on the main site or it does not run. If you upgrade the theme, re-read its default layout before deleting this file: what is reproduced below is structure, and the theme's stylesheet is still what styles it. {% endcomment %} Skip to the content.
